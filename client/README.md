# Nexa — interface web

Pour démarrer Nexa, créer un compte et se connecter, suis le guide principal : [README du projet](../README.md).

Chaque écran connecté possède son fichier dans `src/pages/`. Les composants visuels partagés sont regroupés dans `src/components/`.

Depuis la racine du projet, la commande à utiliser est `npm run dev`. Elle démarre PostgreSQL, l’API et l’interface web.
